# Hoja de ruta y estado del MVP

El MVP para Windows x86-64 está terminado. El desarrollo activo concluyó y el proyecto carece de un compromiso de mantenimiento o soporte. El juego incluye una isla, tres circuitos de luz resolubles en cualquier orden, la restauración del faro, la reconstrucción del puente, la introducción y el desenlace en español e inglés. La distribución portátil se validó en Windows 11. Los requisitos mínimos de hardware siguen sin medirse. [Distribución Windows](windows-distribution.md).

| Hito | Resultado |
| --- | --- |
| Base jugable | Personaje, cámara isométrica, controles, idiomas y primera interacción con el faro |
| Isla y puzles | Isla V3.2, farero visual y tres mecanismos de luz integrados. El faro pide los tres circuitos |
| MVP-01 | Introducción localizada con misión y controles |
| MVP-02 | Desenlace localizado, reinicio limpio y salida |
| MVP-03 | Distribución portátil Windows con plantilla oficial de Godot |
| MVP-04A | Auditoría local de privacidad, documentación, derechos y reproducibilidad |
| MVP-04B | Copia independiente saneada, verificación local y borradores para revisión |
| MVP-05A y 05B | Revisión de licencias y clasificación por archivo |
| MVP-05C | Declaración del propietario, licencias y atribución preparadas |
| MVP-05D | URL pública prevista, integridad y privacidad verificadas |

El [diario técnico](ai-development-log.md), el [diseño](game-design.md) y la [arquitectura](architecture.md) conservan decisiones de implementación y experimentos de fases anteriores. Los conceptos de nuevas islas, generación procedimental y combate quedan como ideas de diseño para posibles derivaciones.
